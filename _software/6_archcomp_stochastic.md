**ArchCompStochasticModels.jl** is a Julia package for benchmark models of the ARCH-COMP stochastic models track.

## Features

- Collection of benchmark models used in stochastic verification workflows
- Documentation for stable and development versions
- CI and coverage tracking for reproducible maintenance
- Package distribution through standard Julia tooling

## Use Cases

- Benchmarking formal verification tools
- Organizing shared stochastic model suites for competition settings
- Reproducing benchmark setups across tool implementations
